"vanna 最新版 2.0 是彻底重写，旧 API 全删了，换成 Agent 架构。新架构文档少、生态没跟上，对我这种每天 2-3 小时的项目是调试黑洞，所以我读了版本变更、降锁到经典 API 末版 0.7.9。这体现的是会读 release notes、会做技术取舍，不是无脑 pip install 最新版。"

② 读源码排错（回答"遇到什么困难"的王牌素材）：

"冒烟时请求一直超时，我读 vanna 源码发现它的 OpenAI\_Chat 会忽略 config 里的 base\_url，把请求误发到 openai 官网。我就自己构造了一个带 base\_url 的 client 注入进去，问题解决。这段经历让我养成了'报错先读源码、不瞎猜'的习惯。"

③ 只读账号（安全设计，BI 岗也吃香）：

"大模型生成的 SQL 不可完全信任，可能写出 DELETE 或带错条件的 UPDATE。所以我给它专门建了 SELECT-only 的只读账号，实测 DELETE 会被拒（错误码 1142），再加应用层校验双保险。这是问数 Agent 的基本安全底线。"
